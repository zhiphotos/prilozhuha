# Студия Дарины (`studio/`)

Мобильное приложение-чеклист с идеями контента для двух Instagram-аккаунтов Дарины:
`rod` — Книга Рода (@darina_balanuca), `zhi` — @zhiphotos. Статический сайт без сборки,
публикуется на GitHub Pages workflow-ом `.github/workflows/static.yml` (деплой с `main`).

## Как добавлять идеи

Все пункты лежат в `studio/data.json`: `{ "updated": "ГГГГ-ММ-ДД", "items": [...] }`.

```json
{ "id": "zhi-reels-31", "acc": "zhi", "sec": "reels",
  "title": "Хук — первая строка, которую видно в списке",
  "text": "Что внутри, сценарий или слайды, хвост. Переносы строк через \n",
  "tag": "охват", "added": "2026-10-15" }
```

- `sec`: `pins` (закрепы), `reels`, `carousels`, `threads`, `ideas` (её черновики, оформленные в посты), `fixes` (что поправить), `pains` (боли аудитории),
  `plan` (карта каналов и ритм),
  `captions` (готовые подписи под посты: `title` — для какого поста, `text` и `full` — подпись целиком; кнопка копирует только `full`).
- `tag`: короткая метка — `охват` / `подписки` / `доверие` для хуков, `польза` / `споры` / `мифы` / `личный опыт` для Threads, любое короткое слово для остального.
- `id` уникальный и **никогда не меняется и не переиспользуется**: по нему в браузере хранятся её отметки «сделано» и «убрано». Новые пункты получают следующий номер в своей серии.
- Новые пункты добавляй **в конец** массива и обновляй `updated`. Всё, чьего `id` она ещё не видела, приложение само покажет в разделе «Новое».
- Ничего не удаляй из `data.json`, чтобы убрать пункт у неё: она убирает сама. Удалять можно только по её просьбе.

## Отчёт от Дарины

В приложении (⋯ → «Скопировать отчёт для Claude») она копирует в чат список сделанного (`✓ [id] …`),
убранного (`× [id] …`) и своих идей (`+ [раздел] …`). Её описания приходят целиком блоком `+ [Описания] название:` … `---` —
сохраняй их в `data.json` как `captions` (title = название, text/full = подпись без изменений), иначе они живут только в её браузере. Свои идеи оформляй в полноценные пункты
(хук, наполнение, хвост) и добавляй в `data.json` с новыми `id`.

## Правила контента

Факты о Дарине — только из её слов. Чего не знаешь — пиши в [квадратных скобках].
Хуки — под холодного зрителя: первая фраза про него, продукт и кодовое слово только в хвосте.

**Тон: сильный хук + спокойное решение.** Хук цепляет (до 10 слов): конфликт, цифра, признание, ошибка,
парадокс, неожиданное наблюдение, информационный разрыв. Спокойствие — после хука: не запугивать
(«пока не поздно», «потеряешь»), не стыдить, простые слова, одна мысль, обязательно — что сделать, чтобы стало
легче. Продажа = ясность, без дожима. Видео «кофе и одна мысль» без орущей музыки, но с сильной первой фразой.
Рилс-сценарий: хук → проблема → скрытая причина → ошибка → решение → пример → финал, новая мысль каждые 2–4 с.
Механика «предмет в первой секунде + бесплатно + можно повторить + находка» работает на подписки — используй её в Книге Роде.
**@zhiphotos — только творчество и проявленность** (актёрские, бэкстейдж, разборы, разговорные для творцов, «Моя неделя»,
полезные карусели для творцов). Находки, архивы, древние книги, монеты, старина — это Книга Рода, не личный аккаунт.
Стратегию бери из её голосовых слов, а не из разборов статистики.
Не повторяй хуки, которые уже есть в `data.json`.

## Кики (продаётся в @zhiphotos)

Приложение для мам: https://kiki-m-m-app-grok.vercel.app/ — Дарина сделала его сама с ИИ, не зная кода,
«устала каждый день придумывать игры для сына», и каждый день улучшает вместе с мамами (~30 в тесте).
Внутри: карточки-игры по возрасту (по минуте, по шагу); колоды по месту и силам («Лень» — мама лежит на диване,
«Готовлю», «Машина», «Парк», «Тихо», «Много энергии»); «нажми 3 раза — вытяни карту»; план игр на день;
режим сна с окном бодрствования по ритму малыша, нормы педиатра, напоминания на экран блокировки, белый шум,
кормление; импорт PDF из AnaBaby; синхронизация со вторым родителем; «Наш год»; огонёк; загадки для мам;
сказки (скоро). Ставится без App Store. Внутри есть карточки, ведущие в курс «Книга Рода».
Кодовое слово в контенте — КИКИ. Цена не решена — пиши [цена].
Главная мысль: «Ты не плохая мама — ты просто устала придумывать». Экран у мамы, не у ребёнка.

В Книге Роде Дарина планирует своё приложение-игру для заполнения книги (уютное хобби) и вайб-рилс
(сериал, чай, сканирование фото, оформление страниц на iPad).

Весь контент строится по её методике: скрытые мысли с конфликтом → новая надежда
(желание → симптомы → ложная причина → корень → новый механизм) → три фильтра хука
(эмоция, простота, новизна) → 10 вопросов убеждения. Threads делятся на пользу, споры, мифы,
личный опыт, и у каждой темы есть «почему подпишутся».

# Приложение «Книга рода» (тест)

Исходники — `kniga-src/` (React + Vite, перенесено из Grok). Собранная версия для GitHub Pages лежит
в `kr-k3nu7rmszt/` — нарочно неочевидное имя, ссылку знает только Дарина, страница с `noindex`.
Пересборка: `cd kniga-src && npm ci --ignore-scripts && npm run build:pages` (пишет в `../kr-k3nu7rmszt`), закоммитить обе папки.

- Данные — только в браузере: состояние и фото в IndexedDB (`lib/rod/idb.ts`, `media.ts`, фото — ссылки `media:<id>`).
  Копия книги в файл `.kniga` — ⚙ на главной (`lib/rod/backup.ts`).
- Страница книги квадратная (20/25/30 см, выбор при печати, `print` в состоянии); все размеры в % стороны листа (на экране `cqw`).
  Охранное поле 10 мм, у корешка 15 мм, вылеты 3–5 мм (`page-style.ts`). Редактор держит текст внутри поля, фото — внутри или на вылет.
  «Печать» на экране книги: блок страниц с вылетами и TrimBox, обложка разворотом с корешком. `components/rod/page-view.tsx` рисует
  страницу на экране, `lib/rod/print-book.ts` — то же самое на холсте 300 dpi для PDF. Меняешь одно — меняй второе.
- Обложка — обычные блоки (`designed: true`), готовые дизайны — `coverDesigns` в `layouts.ts`; старые обложки-картинки переводятся в блоки при запуске.
- Редактор — `components/rod/editor.tsx` (выделение, отмена, перо, вырезка фона, Pinterest), книга с перелистыванием —
  `flipbook.tsx`, шаблоны страниц — `lib/rod/layouts.ts`, стикеры — `lib/rod/page-style.ts`.
- «Вайб» (картинки-ориентиры, в печать не идут) — `components/rod/moodboard.tsx`, `moodboard` в состоянии.
- Перо рисует только в режиме пера (стилус в обычном режиме двигает), удержание выпрямляет линию, «Ровные линии» — всегда прямые.
- Полный шаблон на 100 страниц (7 глав, структура Дарины) — `lib/rod/full-book.ts`, открывается только при `programOpen`.
- Оплата и видео уроков — `lib/rod/config.ts`: `PAY_URL`, `ACCESS_CODES` (сейчас тестовый код «КНИГА»), `LESSON_VIDEO`.
- Серверного ИИ (xAI) на Pages нет: `spa/studio-ai.static.ts` — заглушка.
