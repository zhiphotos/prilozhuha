# Инструменты рисунка для «Книги рода»

Папка переносится в проект как есть. Это не приложение: два инструмента и формат, которым в проект добавляют кисти.

```js
import { createDrawTools } from "./rod-draw-kit/src/index.js";
```

Холст, который возвращает `createDrawTools`, должен лежать **поверх** страницы и быть прозрачным. Бумага под ним. Заливка смотрит только на линии этого холста: пустое место внутри контура красится, линия — стена, край листа стеной не считается.

## Заливка нажатием цвета

Контур одним пальцем или пером, затем нажатие образца цвета:

```js
const draw = createDrawTools({ width: pageWidth, height: pageHeight });
page.append(draw.view);
draw.bind(draw.view);

draw.setBrush("pen");
draw.setSize(4);
// линия приходит сама из bind: инструмент по умолчанию "draw"

colorButton.onclick = () => {
  const result = draw.pressColor(colorButton.dataset.color);
  if (result.reason === "open") {
    // контур не замкнут, до концов result.gap пикселей — лист не залит
  }
};
```

`pressColor` берёт последний настоящий контур, а не случайную точку в конце. Концы ближе порога считаются замкнутыми: порог — это 28px или 2.2 толщины кисти, что больше. Щель дорисовывается той же кистью, заливка кладётся **под** линию.

Повторное нажатие другого цвета перекрашивает этот же контур.

Если фигура собрана из нескольких линий, нажатию цвета не на чем замкнуться. Тогда тап внутрь:

```js
draw.setTool("fill");
// следующий тап по холсту вызовет заливку сам,
// либо без смены инструмента:
draw.fillAt(x, y, "#8c3a3a");
draw.setTool("draw");
```

`fillAt` не красит страницу, если область дырявая и доходит до края холста (`reason: "open"`). Тап по самой линии возвращает `reason: "wall"`. Дырка в один пиксель закрывается сама (`gap: 1`), иначе диагональный штрих пера протекает углами. Широкую дыру так не замазать.

Координаты `pointerDown` / `fillAt` — в CSS-пикселях от левого верхнего угла холста, не в пикселях экрана.

## Движок кистей

Отдельный редактор кистей не нужен. Движок штамповочный, тот же принцип, что у Procreate и Krita, только без их файла:

штрих — это цепочка отпечатков вдоль линии. Расстояние между отпечатками считается само, чтобы медленное ведение пальца не ставило кучу точек в одно место, а быстрое не оставляло дыр.

Кисть — обычный объект. Цвета в нём нет.

| Поле | Зачем |
| --- | --- |
| `tip` | `round` круглое перо, `calligraphy` плоское, `image` картинка |
| `spacing` | доля толщины между штампами: `0.08` сплошная линия, `1.5` отдельные следы |
| `hardness` | `1` жёсткий край, `0` мягкий. Только для `round` |
| `squeeze` | высота плоского пера относительно ширины |
| `angle` | наклон в градусах. У каллиграфии это срез пера |
| `angleMode` | `fixed`, `direction` (по ходу линии), `random` |
| `sizeJitter`, `opacityJitter`, `scatter` | дрожание от 0 до 1 |
| `opacity` | плотность одного штампа |
| `pressureSize` | сила нажатия стилуса меняет толщину |

Уже лежат в наборе: Перо, Акварель, Тушь, Каллиграфия, Уголь, Шов, Лист.

Своя круглая кисть:

```js
draw.addBrush({
  id: "berry",
  name: "Ягода",
  tip: "round",
  spacing: 1.4,
  hardness: 1,
  defaultSize: 8,
  minSize: 4,
  maxSize: 24,
});
draw.setBrush("berry");
```

Свой PNG (форма чёрная или белая, фон прозрачный — цвет всё равно берётся текущий):

```js
await draw.addBrushFromFile(file, {
  name: "Дубовый лист",
  spacing: 0.9,
  angleMode: "direction",
});
```

Пачка файлом — `example/pack.json`. Картинке в такое же JSON кладётся `image` со строкой `data:image/png;base64,...`.

```js
await draw.loadPack(jsonOrFileOrUrl);
const pack = draw.exportPack(); // текущий набор, чтобы его сохранить и отдать
```

Формат называется `rod-brush-pack/1`. Файл Photoshop `.abr` сюда не кладётся: из него заранее экспортят PNG кончика. Холст из-за этого менять не нужно.

## Что не делать при встройке

- Не рисовать бумагу на `draw.view`. Слой очищается при каждой перерисовке.
- Не заливать цветом «весь холст под контуром», если контур открыт. Это уже запрещено внутри `pressColor` и `fillAt`, интерфейсу остаётся сказать об этом.
- Не зашивать цвет в кисть. Образец цвета и есть заливка.
