# prilozhuha

## Студия (`studio/`)

Идеи контента для двух аккаунтов — Книга Рода и @zhiphotos — по разделам: закрепы, рилс,
карусели, Threads, идеи, что поправить, боли аудитории. Отмечай сделанное, убирай лишнее,
добавляй свои идеи. Новое от Claude появляется в разделе «Новое».

Адрес после публикации на GitHub Pages: `https://zhiphotos.github.io/prilozhuha/studio/`

На телефоне: открой адрес → «Поделиться» → «На экран Домой». Студия откроется как приложение.

Отметки хранятся в браузере телефона. Перенос на другое устройство и отчёт для Claude — в меню ⋯.

Как Claude добавляет пункты — в `CLAUDE.md`.
