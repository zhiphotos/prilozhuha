# ИИ-система «Книги рода»: что хотим и как подключать

Решения Дарины от 2026-11-04. Этот файл – единственное место, где собран план ИИ. Состояние кода: этап 1 (ветка `claude/ai-engine-stage1`, PR 111).

## Принципы
- ИИ входит в цену программы, без доплаты, в **бесплатных обновляемых лимитах**. Безлимит не обещаем.
- Никаких неожиданных списаний: нет платного запасного провайдера, при исчерпании бесплатной квоты запросы останавливаются, пользователь видит дату обновления лимита.
- Все лимиты проверяет сервер (токен доступа), не браузер. Владелец = хеш `order` из подписанного токена.
- Лимиты меняются без кода (`AI_LIMITS`). Аварийный выключатель: `AI_ENABLED` (по умолчанию выключено).
- Любое изменение дерева ИИ только предлагает, применяется после подтверждения. Подтверждённые факты и предположения различаются. Ничего не выдумывать (людей, даты, источники, номера дел).
- Модели заменяемы: новый адаптер в `kniga-api/lib/ai/providers.js`, интерфейс приложения не меняется.

## Что хотим (функции)
1. **ИИ-генеалог.** Понимает дерево книги, отвечает на вопросы, находит пробелы и противоречия, предлагает связи, составляет план исследования и вопросы для интервью, объясняет вывод. Контекст дерева передаётся с клиента кратким описанием. Инструкции и книги для него Дарина готовит отдельно (не блокирует разработку).
2. **Поиск по архивам.** Внешние источники с сохранением названия, ссылки, архива, номера дела, даты, достоверности и объяснения. Совпадение ФИО не считать родством. Закрытые архивы честно помечать. Плюс поиск по своим материалам книги (интервью, документы, письма, истории) со ссылками на место.
3. **Whisper.** Расшифровка интервью любой длины, сначала whisper.cpp в браузере (WASM, Web Worker), частями, с сохранением прогресса и повтором неудачных фрагментов; временные метки; плеер с переходом к месту текста; редактор. Если устройство не справляется, приложение честно говорит.
4. **Разделение говорящих.** Сначала упрощённое («Говорящий 1/2/3») с ручным исправлением и назначением имён, без обещания точности. Архитектура допускает позже pyannote или WhisperX.
5. **OCR.** Подключаемый адаптер. Сначала бесплатные варианты с русским (Tesseract.js только для печатного текста; Cloudflare, если есть модель), Xiaomi-OCR-0 как отдельный адаптер на свой сервер при желании. Нужны не только текст, но и поля (ФИО, даты, места, связи), сохранение оригинала и ссылка факта на документ и страницу.
6. **Единый архив.** Интервью, документы, находки и истории в одном поиске по смыслу, с ответами со ссылками на страницы и метки времени.

## Этапы (по одному PR)
1. Общий ИИ-слой, проверка доступа, квоты – **сделано в PR 111**.
2. Файловое хранилище и очередь задач.
3. Whisper и редактор расшифровок.
4. Разделение говорящих.
5. OCR.
6. ИИ-генеалог (интерфейс, контекст дерева).
7. Поиск по семейному архиву.
8. Внешний архивный поиск.
9. Интеграционные тесты и оптимизация.

## Как подключить (когда PR будет слит и выложен, только по слову Дарины)
Переменные окружения проекта `kniga-roda-api` в Vercel (секреты вписывает владелец, в git их нет):
| Переменная | Что это |
| --- | --- |
| `AI_ENABLED` | `1` включает ИИ, любое другое значение выключает всё |
| `CF_ACCOUNT_ID`, `CF_API_TOKEN` | Cloudflare Workers AI, **бесплатный план**, платный тариф не подключать без решения владельца |
| `CF_TEXT_MODEL` | необязательно, по умолчанию `@cf/meta/llama-3.1-8b-instruct` |
| `AI_LIMITS` | необязательно, JSON с лимитами, например `{"text":{"per":"day","user":15,"global":300}}` |

Проверка: `POST /api/ai-status` показывает, что включено и остатки. Без ключей функции отвечают «не подключено».

## Лимиты по умолчанию (оценочные, подтвердить)
Текст 20 в день на человека (общий потолок 400 в день), аудио 300 минут в месяц, OCR 100 страниц в месяц, архивы 10 в месяц. Периоды по Москве.

## Открытые вопросы
- Cloudflare: общий бесплатный запас 10 000 Neurons в сутки на весь аккаунт; нужен аварийный порог. Создавать ли R2 (файловое хранилище) бесплатно и с какими лимитами на файлы.
- Vercel Hobby рассчитан на некоммерческое использование, для платного продукта, вероятно, нужен другой тариф (решает владелец).
- Один человек с доступами разных видов (оплата, код, платформа) получает разные лимиты и разные облачные книги.
- `/api/layout` не проверяет токен (расходует платный ключ): закрыть отдельным PR.
- Реальные Cloudflare и Upstash на этапе 1 не проверялись.

## Решение Дарины 2026-11-04 про Xiaomi и поиск
- Xiaomi-OCR-0 (распознавание документов) не нужен как главное. Дарина хочет ИИ **для поиска по архивам, для написания художественных текстов и для поиска по интернету по архивам**. Это задачи текстовой модели и веб-источников, а не OCR.
- Художественные тексты: связь с исходным фактом, придуманные детали помечаются как вымысел и не выдаются за воспоминания.
- Поиск по интернету по архивам: только открытые каталоги и документы с проверкой условий использования сайтов, каждая находка со ссылкой на источник, без выдуманных номеров дел.
- OCR остаётся подключаемым адаптером на потом (Tesseract.js для печатного текста бесплатно; Xiaomi только на собственном GPU и с согласия владельца, русский язык не проверен).
