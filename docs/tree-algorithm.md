# Как приложение строит древо (весь алгоритм)

Файлы: `kniga-src/src/lib/tree/from-people.ts` (данные), `layout.ts` (раскладка), `auto-links.ts` (автосвязи при вводе), `TreeStage.tsx` (линии), `exportPoster.ts` (PNG/PDF).

## Шаг 0. Источник правды
Список «Люди». Древо только отражает его. У каждого человека: кем приходится (слово), `parents` (до двух родителей), `siblingOf`, `spouse`, `spouseStatus`, `moreSpouses`, линия (`line`: мама/папа), сторона и место, выбранные вручную.

## Шаг 1. Роль по слову «кем приходится» (`roleOf`)
я, муж/жена, мама, папа, бабушка/дедушка, прабабушка/прадедушка/предок, дядя/тётя, брат/сестра/двоюродный, сын/дочь, внук/внучка; «брат/сестра мужа/жены» = родной человек супруга. Остальные = other. Пол: из карточки, иначе по слову.

## Шаг 2. Люди → данные древа (`treeFromPeople`)
1. Центр = запись «я»; если её нет, создаётся запасное «Я».
2. Каждый человек становится узлом (имя, отчество, фамилия, девичья, годы, фото).
3. Мама и папа «меня»: первые по слову, но не те, кого кто-то указал родителем не-брата (чужая мать/отец, свекровь).
4. Если родителей нет, но нужны братья, бабушки или дяди, создаются пустые «Мама»/«Папа».
5. Для каждого человека связь с родителями по приоритету:
   - явные `parents` (брат/сестра не может быть моим ребёнком, такие выборы игнорируются);
   - иначе `siblingOf`: встаёт в тот же союз родителей, что у названного (у него родителей нет: рисуются общие пустые Мама и Папа);
   - иначе по слову: брат/сестра → родители «меня»; сын/дочь → мой союз; дядя/тётя → пара бабушки и дедушки своей линии (при одном известном рядом пустое место).
6. Прабабушки/прадедушки линии → родители бабушки/дедушки той линии, если их никто не заявил иначе.
7. Брат/сестра супруга → родители супруга (при необходимости пустые Мама и Папа).
8. Браки: `spouse` + статус и годы; `moreSpouses` — 2-й и далее браки; если у «меня» есть супруг, дети с одним родителем (не из файла) переходят в общий союз.
Итог: люди, союзы (партнёры + дети), центр.

## Шаг 3. Поколения (`assignGenerations`)
Граф: супруги = 0, родитель→ребёнок = +1. Обход в ширину от каждого, затем сдвиг, чтобы минимум был 0. Так предки сверху, потомки снизу.

## Шаг 4. Блоки (`tidyOnce`)
- Блок = группа супругов одного поколения (`spouseGroups`, порядок внутри пары `orderGroup`: выбор пользователя, мужчина слева, иначе по возрасту; при нескольких браках главный в середине).
- Предки выбранного: их пары, у обоих из которых есть родители, разводятся: один главный (по линии выбранного, глубине предков), второй «призрак» под своими родителями; брак тянется между ними.
- Родительский блок ребёнка: родители на уровень выше.

## Шаг 5. Порядок слева направо
- Восходящая схема: сторона отца целиком слева, мамы справа, на каждом уровне.
- Дети разных браков группами по порядку супругов.
- Прямой род по центру, боковые ветки (братья и сёстры предков, их потомство) уходят к краям: отцовская левее, материнская правее; чем старше предок, тем дальше.
- Ветки без предков выбранного (пришли через брак) в конец; ручной `rank` главнее.

## Шаг 6. Горизонтальные координаты
1. Центры блоков; родители над своим ребёнком из прямого рода (над выбранным над ним самим).
2. Сверху вниз: дети разорванной пары под серединой между супругами.
3. Свободная полоса вокруг выбранного и его братьев/сестёр (4 шага): дальние кузены не втискиваются рядом.
4. Если ряд тесен, блок со всем потомством сдвигается вправо (контуры).
5. Супруги не дальше `SPLIT_LIMIT` (5 карточек) и без чужих между ними; иначе пара ставится рядом (повтор до 6 раз с запретом пары), последняя попытка без разведения.
6. Подтяжка семей: ряды тянутся к родителям и детям; семья супруга собирается рядом с ним; последние проходы сверху вниз.
7. Предки в строгой восходящей схеме не скрываются никогда.

## Шаг 7. Вертикаль и линии (`layoutTree`)
- Строки по поколению (`ROW_H`).
- Линия брака между супругами с плашкой «БРАК»; от её середины вниз линия детей, ниже ветвление к каждому ребёнку.
- Далёкие супруги (каждый под своими родителями): скобка до общей шины.
- Шины разных семей одного ряда идут по разным «дорожкам», не сливаясь.
- Далёкие связи родственников со стороны: бледный пунктир или значок ↑ у карточки (только их, не обычных детей).

## Шаг 8. Показ и экспорт
Режимы радиуса (`sliceByRadius`): «Кровные», «Все» и пр. Рисование в `TreeStage.tsx`. PNG/PDF: `exportPoster.ts`, лист-карта и листы по 3 ряда.

## Известные слабые места
- Большое древо: длинные линии (идея: сворачивать боковые ветки в «+N»).
- Сводные братья/сёстры (один общий родитель): сейчас рисуются как дети разных союзов, надо отдельно доработать.
- Выбор «брат или сестра» копирует родителей (`onSiblingSet`), из-за чего ошибочный выбор может исказить данные.
